# **App Name**: Arkā Solar

## Core Features:

- Dynamic Savings Calculator: An interactive tool allowing users to estimate ROI, payback period, and monthly savings via intuitive sliders.
- AI Energy Advisor tool: A feature that uses reasoning to analyze monthly electricity consumption and roof area to recommend an optimized system size and custom subsidy breakdown.
- Multilingual Hero Interface: A high-impact landing section featuring premium imagery with Hindi catchy headlines and 'Get a Quote' calls to action.
- Interactive Installation Timeline: A visual step-by-step UI representing the consultation, survey, design, and after-sales support workflow.
- Environmental Impact Tracker: A live visualizer converting solar capacity into CO2 offset and equivalent trees planted data for ecological motivation.
- Smart Lead Generation Engine: A integrated popup form designed to capture user details including pincode and monthly bill for tailored follow-up.
- Service Area & Benefit Grid: Detailed cards outlining mission, vision, values, and localized service expertise.

## Style Guidelines:

- Primary color: Deep Emerald Green (#1B4332) to symbolize sustainability and growth.
- Background color: Mint Frost (#F7FAF8), a heavily desaturated variant of the primary green for a clean, light medical feel.
- Accent color: Solar Amber (#FCD34D) used for sliders and buttons to reflect sunlight and high energy levels.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, tech-focused engineering look. Body font: 'Inter' (sans-serif) for high readability across metrics.
- A card-based layout featuring 24px corner rounding and soft 'inner' shadows for a premium, tactile physical feel.
- Monolinear vector icons representing hardware components and ecological benefits (trees, CO2 particles).
- Smooth slider transitions in the calculator and staggered fade-ins for the vision/mission cards.
